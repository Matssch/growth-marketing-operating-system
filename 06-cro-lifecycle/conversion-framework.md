# Conversion Framework

I treat CRO as structured problem solving.

## Process

1. Find the drop
2. Understand the behaviour
3. Form a hypothesis
4. Change one meaningful thing
5. Measure the effect
6. Scale, improve or kill

## Inputs

- Funnel data
- Landing-page performance
- Search intent
- Heatmaps / session behaviour
- Form completion
- Sales feedback
- Customer interviews
- Device breakdown
- Traffic source

## Typical questions

- Is the message relevant to the audience?
- Is the value clear quickly enough?
- Is the CTA right for the level of intent?
- Is there unnecessary friction?
- Is there enough proof?
- Does mobile perform differently?
- Is poor conversion actually a targeting problem?

CRO starts with diagnosis, not button colours.
