# Growth Questions

These are examples of questions I want the data model to answer.

## Acquisition

- Which channels generate the strongest pipeline per euro?
- Where is CAC increasing?
- Which campaigns generate cheap leads but weak opportunities?
- Which segment performs best by channel?

## Funnel

- Where is the largest conversion loss?
- Which acquisition source creates the strongest opportunity rate?
- How does Sales cycle differ by segment?
- Which funnel stage changed most month over month?

## Accounts

- Which high-fit accounts show increasing engagement?
- Which account tiers create the most pipeline?
- Which buying groups are under-engaged?

## Revenue

- Which campaigns are connected to closed-won revenue?
- What is payback by segment?
- Which customer groups have the strongest value?

SQL is useful here because I can move from a dashboard result into the underlying data instead of stopping at the chart.
