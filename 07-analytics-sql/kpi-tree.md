# KPI Tree

## North-star commercial layer

**Revenue / ARR**

Supported by:

- New customers
- Expansion
- Retention
- Average contract value

## Pipeline layer

- Pipeline created
- Marketing-sourced pipeline
- Marketing-influenced pipeline
- Opportunity volume
- Opportunity value
- Win rate

## Funnel layer

- Lead → qualified
- Qualified → opportunity
- Opportunity → win
- Sales cycle

## Acquisition layer

- Spend
- Sessions
- Leads
- CPL
- Cost / opportunity
- CAC

## Diagnostic layer

- CTR
- CPC
- Landing-page CVR
- Search visibility
- Engagement
- Email performance

The further down the tree I go, the more diagnostic the metric becomes.

The top tells me whether growth happened.

The bottom helps explain why.
