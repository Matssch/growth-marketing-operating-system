# KPI Dictionary

| KPI | Definition | Why it matters |
|---|---|---|
| CAC | Acquisition spend / new customers | Commercial acquisition efficiency |
| CPL | Spend / leads | Early acquisition efficiency |
| Cost / Opportunity | Spend / opportunities | Connects media to pipeline quality |
| Pipeline / Spend | Pipeline value / marketing spend | Commercial leverage |
| Lead → Opportunity | Opportunities / leads | Lead quality + funnel effectiveness |
| Win Rate | Closed won / opportunities | Pipeline quality + Sales effectiveness |
| ACV | Contract value / customers | Customer value |
| Payback | CAC / monthly gross contribution | Speed of recovering acquisition cost |
| Branded Search | Search demand for brand terms | Demand / awareness signal |
| Account Engagement | Meaningful activity from target account | ABM prioritisation signal |

Every KPI should have:

- One definition
- One data source
- One owner
- One reporting frequency
- One reason it matters
