# Budget Allocation

I would start with an initial allocation, not a fixed annual media plan.

## Example starting allocation

| Area | Budget | Role |
|---|---:|---|
| Paid Search | €75K | Capture demand |
| Paid Social | €55K | Create + capture demand |
| ABM / account programs | €45K | High-value accounts |
| SEO / content | €45K | Compound organic demand |
| CRO / experimentation | €25K | Improve conversion |
| Lifecycle / CRM | €20K | Nurture + activation |
| Partnerships / tests | €20K | New growth sources |
| Flexible reserve | €15K | Move toward evidence |

Total: **€300K**

## Reallocation rule

Budget moves based on:

- Incremental pipeline
- Opportunity quality
- CAC
- Conversion
- Segment performance
- Capacity to scale
- Confidence in measurement

The objective is not to protect the original plan.

The objective is to place the next euro where it has the strongest expected return.
