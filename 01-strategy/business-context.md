# Business Context

## Company

FlowOps is a fictional European B2B SaaS company that helps growing businesses manage operational workflows across teams.

The company has reached approximately **€8M ARR** and wants to build its next stage of growth.

The company and performance data in this project are simulated. The purpose is to show the thinking, structure and analysis behind the growth system.

## Starting point

- ARR: €8M
- Average contract value: €15K
- Annual growth marketing budget: €300K
- Marketing-influenced pipeline target: €3M
- Sales motion: sales-assisted
- Customer mix: SMB, mid-market and enterprise
- Current challenge: growth activity exists, but it is not yet managed as one connected system

## The real problem

The problem is not “we need more marketing.”

The company needs to know:

- Which segments create the best commercial return?
- Where is demand already present?
- Where does demand need to be created?
- Which channels create pipeline rather than activity?
- Where does the funnel lose good prospects?
- Which accounts need a more targeted Sales + Marketing approach?
- What should receive the next euro of budget?

That changes the role of Marketing.

Instead of running separate channel plans, Marketing needs to connect **market choice, acquisition, conversion, pipeline and revenue**.

## Constraint-led growth

I would start by identifying the biggest current constraint.

Examples:

- Low awareness → demand creation problem
- Low high-intent traffic → demand capture problem
- Strong traffic, weak conversion → CRO problem
- High lead volume, poor opportunity rate → targeting or qualification problem
- Strong opportunities, weak close rate → Sales / proposition problem
- Strong acquisition, weak retention → product or lifecycle problem

The point is simple:

**Do not optimise the part of the funnel that is already working while the real constraint sits somewhere else.**

## Commercial objective

The first target is **€3M in marketing-influenced pipeline**.

But that target is not treated as a Marketing vanity number.

The system also needs to improve the quality and predictability of growth by answering:

- Which activity creates the strongest opportunities?
- Which segments convert best?
- Which acquisition sources scale efficiently?
- Which signals help Sales prioritise accounts?
- Which investments create compounding growth?

That is the foundation for the rest of the operating system.
