# 10 — Growth Cadence

A growth system only works if decisions happen regularly.

The operating cadence connects channel execution with commercial outcomes.

## Weekly — Run the business

Focus:

- Performance movements
- Pipeline created
- Priority accounts
- Funnel blockers
- Active experiments
- Immediate actions

Output:

**What changed this week, and what are we changing because of it?**

## Monthly — Improve the system

Focus:

- Channel economics
- Segment performance
- Funnel conversion
- CAC
- Pipeline contribution
- Budget shifts
- Experiment learning

Output:

**Where should we increase, reduce or change investment?**

## Quarterly — Revisit the assumptions

Focus:

- ICP
- Segment attractiveness
- Market shifts
- Positioning
- Budget allocation
- Growth constraints
- Major bets

Output:

**Are we still solving the right growth problem?**

## Run + Change

I separate work into two modes.

### Run

Protect performance.

- Campaign management
- Reporting
- Funnel health
- Lead routing
- SEO hygiene
- CRM operations

### Change

Build the next level.

- New segments
- CRO
- New channels
- ABM
- New lifecycle plays
- Measurement improvements
- Strategic experiments

A team that only runs becomes stagnant.

A team that only changes breaks what already works.

Good growth management needs both.
