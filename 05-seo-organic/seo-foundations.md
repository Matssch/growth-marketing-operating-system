# SEO Foundations

Before scaling content, I want to know the site can actually be discovered, understood and converted.

## Technical checks

- Crawlability
- Indexability
- Robots.txt
- XML sitemap
- Canonicals
- Redirects
- Status codes
- Internal linking
- Site architecture
- Core Web Vitals
- Structured data
- Mobile usability

## Measurement

- Google Search Console
- GA4
- Rank / visibility tracking
- Landing-page conversion
- Assisted pipeline

## Priority

I rank issues by:

**Commercial impact × SEO impact × effort**

A technically perfect page with no relevant search demand is not automatically a priority.

SEO work should follow the growth opportunity.
